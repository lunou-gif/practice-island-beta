# Practice Island (beta 0.1)

A free web app for kids' home mouth-exercise practice. Each exercise has a demo, a camera mirror and a game. Practice earns treasure that kids spend on building their own island, and they can walk their buddy around it. The look, the games and the buddies change with the child's age: 4-5, 6-8 and 9+.

## Put it online (GitHub Pages, same as Brave Steps)
1. Create a new public repo, for example `practice-island`.
2. Upload `index.html`, `manifest.json` and the three `icon-*.png` files to the repo root.
3. Settings > Pages > Deploy from branch > `main`, folder `/ (root)`.
4. On each family's iPad or iPhone, open the Pages link in Safari, tap Share, then Add to Home Screen. The camera mirror needs this (or any normal https page); it can't run inside a preview frame.

## Setting up the 3 beta kids
- Gear icon > answer the grown-ups question > Add a kid (name + age picks the look).
- Plan and progress: replace the starter exercises with the therapist's plan, set repeats or holds, and pick a cartoon demo. You can attach a video saved on that device or paste a video link.
- Share this plan: set the plan up once, then send the plan link to a family. They open it and pick which kid gets it. Names and progress never leave the device.
- Progress: copy the weekly summary for the therapist (days practiced, streak, times per exercise, easy/okay/hard ratings).

## Privacy
No accounts, no ads, no tracking. All data stays in the browser on that device (use Backup in the grown-ups area to move it). The mirror shows the camera live and never records or uploads.
